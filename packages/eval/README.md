# @toolgate/eval

Jev given/expected/actual evaluation CLI. `toolgate validate`, `toolgate inspect --limit 1`, and `toolgate evaluate --split all`. Evaluation requires TYPESAFE_API_KEY. The core dataset and configuration are bundled; --dataset and --config accept custom files.

Node.js 24+, ESM, MIT. Experimental; model decisions are not a replacement for application authorization. Local packages are not published to npm.
